漏洞名称：未授权访问隐藏测试沙盒

1. 挑战概述
漏洞类别：敏感信息泄露 / 测试环境未下线
挑战目标：通过前端代码审计，找到并访问一个未在导航菜单中公开的智能合约代码实时编译与测试沙盒页面。

3. 漏洞危害与加固建议
实战危害展示：在真实企业生产环境中，遗留未下线的“测试沙盒”、“测试后台”是极其危险的攻击跳板。由于测试页面通常缺乏严格的安全过滤且绑定了高权限调试接口，攻击者一旦通过前端 JS 源码扒出路径，就能直接利用沙盒功能测试恶意代码、调用未授权 API 甚至穿透内网。

修复方案：
1. 生产环境剥离测试代码：在执行 CI/CD 打包发布流程时，必须通过环境变量区分开发环境与生产环境，严禁将内部测试组件与沙盒路由打包进线上代码。
2. 服务端路由鉴权拦截：不能仅靠在前端界面隐藏菜单按钮来限制访问。所有涉及调试、管理或沙盒测试的路由，必须在网关层或后端接口强制校验管理员权限 Token。
