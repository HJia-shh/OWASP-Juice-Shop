3. 实战危害与加固建议
实战危害展示：这种业务型备份文件的泄露，其危害往往比纯技术型配置文件更大。销售备份中通常包含未使用的代金券、高净值客户名单、历史交易流水或内部定价策略。结合“客户端时间校验失效”等业务逻辑漏洞，黑客可以直接将这些历史凭证变现。

修复方案：
1. 彻底禁用空字节解析：在 Node.js 中，虽然高版本已经对某些空字节路径遍历进行了修补，但最佳实践依然是在应用全局中间件中，强制过滤掉所有请求 URL 中的 `%00` 字符。
2. 隔离静态资源与敏感文件：FTP 或 Public 目录只应存放真正的静态渲染资源。任何商业备份、数据导出文件必须存放在 Web 根目录之外，并通过高权限的 API 接口配合长期/短期访问凭证进行安全的受控分发。
