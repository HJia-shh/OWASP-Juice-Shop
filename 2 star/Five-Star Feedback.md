漏洞名称：批量删除 5 星反馈 / 管理员越权操作

1. 挑战概述
漏洞类别：访问控制缺陷 / 高危越权操作
挑战目标：利用管理员权限，通过后台 API 接口成功批量删除系统中的所有 5 星用户反馈。

2. 漏洞发现线索与复现过程

在 Web 渗透和安全加固测试中，删除、修改等具有破坏性的高危 API 接口往往是防御的重点。攻击者通常需要先获取管理员凭据，再通过抓包分析出对应的删除接口。

3. 漏洞危害与加固建议
实战危害展示：如果高危的删除或清空接口，没有在后端实施严格的多重身份确认或二次密码校验，一旦攻击者通过 XSS、越权或弱口令劫持了管理员账号，就能瞬间通过脚本清空整个数据库的核心业务数据，造成毁灭性的数据丢失。

修复方案：
1. 严格的后端越权拦截：高危敏感接口必须在后端网关及控制器层强制校验操作者的角色是否为最高管理员。绝对不允许仅凭前端按钮控制。
2. 二次确认机制：针对删除全站数据、批量清空等极度危险的不可逆操作，后端必须在 API 层面要求管理员在请求头或请求体中再次提交当前密码或动态验证码，从机制上杜绝自动化脚本或越权 Token 瞬间遭到恶意破坏。
